# KORA Environment Configuration — Changelog

## [1.0.0] - 2026-07-27

### Added

- Arquitectura de configuración por entorno.
- Archivos de ejemplo sin secretos.
- Adaptador público para la arquitectura multipágina.
- Generación determinística de `window.__KORA_ENV__`.
- Validaciones de seguridad y separación ERP/Agentes.
- Preparación para development, staging y production.
- Dry-run y confirmaciones obligatorias para el script administrativo.
