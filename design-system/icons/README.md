# Iconografía

Creditek utiliza exclusivamente la librería oficial Lucide para iconos de interfaz.

- Versión aprobada: `lucide@1.27.0`.
- CDN permitido: `https://unpkg.com/lucide@1.27.0`.
- No se permite `latest`, rangos abiertos ni versiones flotantes.
- Los iconos decorativos deben tener `aria-hidden="true"`.
- Los botones que muestran solo un icono deben incluir `aria-label`.
- Los emojis se reservan para contenido del negocio, no para navegación o acciones.
- Cada aplicación debe cargar una versión fijada de Lucide y llamar `renderLucideIcons`.
